# README – Elite Sports
Sobre o Projeto

O Elite Sports é um sistema de loja esportiva desenvolvido em C# utilizando Programação Orientada a Objetos (POO).
O projeto simula uma loja virtual da Copa 2026 com funcionalidades de login, produtos, carrinho, pagamento e finalização de pedidos.

O sistema foi criado em versão Console Application para fins de estudo e prática de lógica de programação e POO.

🚀 Funcionalidades

✅ Login de usuário
✅ Cadastro de produtos
✅ Controle de estoque
✅ Carrinho de compras
✅ Cálculo automático do total
✅ Pagamento via PIX
✅ Finalização de pedidos

📂 Arquivos do Projeto

O projeto possui duas versões do sistema:

🔹 Versão Interativa

Arquivo onde o usuário pode interagir diretamente pelo console, realizando ações como:

escolher produtos
adicionar itens
navegar pelo sistema
inserir informações manualmente

Essa versão foi criada para deixar o sistema mais dinâmico e próximo de uma aplicação real.

🔹 Versão Automática

Arquivo utilizado para demonstração rápida do sistema.
Nele, todas as informações já estão previamente cadastradas e executadas automaticamente, mostrando diretamente o funcionamento completo da aplicação.

Essa foi a versão utilizada para apresentação do projeto.
